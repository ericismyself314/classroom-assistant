# 课堂助手使用指南

本文面向第一次使用软件的人。

## 第一次打开

1. 打开应用后，先填写一个学期。
2. 添加至少一门课程；课程名称是必填项，课程代码和每周上课时间可以之后再补。
3. 在准备模型区域点击“准备离线模型”。第一次准备可能需要较长时间和数 GB 磁盘空间。
4. 模型没有准备好时，也可以先完成课程设置，之后在“设置”页继续准备。

## 处理一节课

1. 在“本周”或“课程”页打开对应课程。
2. 新增课堂并选择日期。
3. 选择“上传录音”，或选择“导入转写文字”。文字可以带 `[00:35]` 这样的时间戳。
4. 等待处理完成。
5. 在课堂详情中查看课堂概览、时间轴、知识点、重要事项和完整转写。

## 如何理解重要事项

软件会尝试找出老师明确宣布的作业、考试、截止时间、调课和活动，并显示对应原文证据。标记为“待核对”的内容不是最终结论，需要回听录音或查看原文。

不要把自动整理结果当成学校或老师的正式通知。涉及考试安排、成绩、截止时间等信息时，请以学校和老师的正式通知为准。

## 修改和重新处理

- 转写中有错字时，可以直接修改原文片段。
- 修改转写后，可以选择“仅重新分析”，让课堂笔记使用修正后的文字。
- 语言选错或识别质量不佳时，可以在“识别设置”中选择正确语言并重新转写。
- 重新处理前的结果会保存在历史版本中，便于对照。

## 数据备份

在“设置”页可以导出备份。备份包含录音、转写、课程和课堂笔记，属于个人敏感资料，请不要上传到公开 Issue 或群聊。

## 遇到问题

先在“设置”页运行自检，确认模型状态和数据目录。提交 Issue 时，请只提供脱敏后的错误信息，不要上传录音、完整转写、数据库或 API 密钥。
