# 数据存储与隐私说明

---

## 一、数据全部在本地

「课堂助手」是**离线优先**的本地应用。除首次下载模型需要联网外，录音、转写、分析与检索**全部在本机完成**，不会向任何服务器上传课堂内容。

---

## 二、数据目录结构

默认根目录：`%APPDATA%/ClassroomAssistant\`
（即 `C:\Users\<用户名>\AppData\Roaming\ClassroomAssistant\`）

可在「设置」页修改数据目录（例如改到 D 盘），真实位置记录在该目录下的 `app_root.json`。

```
ClassroomAssistant\
├─ app_root.json          # 记录真实数据目录位置（可改盘）
├─ database\
│  └─ classroom-assistant.db   # 主数据库（SQLite，WAL 模式）
├─ audio\
│  └─ <学期>/<课程>/<课堂>/original.<ext>   # 原始录音（去重按 sha256）
├─ transcripts\
│  └─ <课堂>/...          # 转写文本与片段
├─ models\
│  ├─ speech\             # Qwen3-ASR-0.6B 语音模型
│  └─ llm\
│     ├─ <模型id>.gguf     # 默认 Qwen3-4B 文字模型（可兼容导入其它 GGUF）
│     └─ bin\             # llama.cpp 服务端 llama-server.exe
├─ logs\                  # 应用日志
└─ exports\               # 备份导出/恢复临时文件
```

> **录音与转写**放在 `audio/` 与 `transcripts/`，以「学期/课程/课堂」分层，便于人工核对与迁移。
> **数据库**只存结构化结果（概览、重要事项、片段、课表），不重复存音频本身。

---

## 三、数据库表（概览）

| 表 | 用途 |
|----|------|
| `semesters` | 学期（名称、起止日期、时区） |
| `courses` | 课程（名称、代码、教师、教室、语言模式、配色） |
| `course_slots` | 上课时间槽（星期、起止时间、起止周、教室） |
| `class_sessions` | 单次课堂记录（日期、状态、音频路径/hash、语言、模型） |
| `transcript_segments` | 带时间戳的转写片段 |
| `session_topics` | 课堂主题/概览 |
| `important_items` | 重要事项（类别、标题、详情、原始日期、归一化日期、证据 JSON、是否已确认/完成） |
| `processing_jobs` | 处理任务（状态、阶段、进度、错误） |
| `fts_index` | FTS5 全文索引（trigram 分词，覆盖转写与事项） |
| `app_settings` | 用户设置（密钥**不**明文存此表，见下） |

## 四、敏感信息加密（DPAPI）

- 若使用「OpenAI 兼容」提供方，API 密钥**不会**写入数据库明文。
- 通过 `src/backend/credential.py` 使用 **Windows DPAPI**（`CryptProtectData`）加密，仅当前 Windows 用户、当前设备可解密。
- 数据库 `app_settings` 中只保存 `openai_api_key_set = "1"` 这类标记位。
- 设置接口 `GET /api/settings` 返回时主动剔除密钥字段。

> 说明：DPAPI 与 Windows 用户账户绑定，重装系统或更换用户后将无法解密旧密钥——这是预期的安全行为。导入/导出备份时密钥不随 ZIP 导出。

---

## 五、备份与恢复

- **备份**：设置页「备份」→ 下载一个 ZIP，内含 `database/`、`audio/`、`transcripts/`、`logs/`。
  备份在本地生成后通过 `GET /api/backup?download=1` 以附件形式下载，**不离开本机**。
- **恢复**：设置页「恢复」→ 选择此前的 ZIP，会覆盖当前数据目录的对应内容。
- **建议**：重装系统、换机、系统大版本升级前，务必先备份；备份文件含课堂隐私，请妥善保管。

---

## 六、网络访问说明

| 场景 | 是否联网 | 说明 |
|------|----------|------|
| 首次下载语音/文字模型 | 需要 | 从 HuggingFace / GitHub 拉取，仅此一次 |
| 日常录音→转写→分析 | 不需要 | 全本地 |
| 使用本机 Ollama | 不需要 | 本地服务 |
| 使用 OpenAI 兼容 API | 需要 | 仅当你主动配置第三方 API 时 |

应用不会在后台静默上传任何数据。

---

## 七、隐私建议

- 不要在公共电脑勾选「记住密钥」。
- 备份 ZIP 含可识别的课堂内容，勿随意分享。
- 若需彻底删除某次课堂，在「课程/课堂」里删除，会同时清理音频与转写文件；数据库层面采用归档而非硬删，避免误删历史（如需硬删可后续扩展）。
