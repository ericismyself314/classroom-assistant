## 一、当前交付结论

- **上传录音识别失败**（2026-09-04 用户反馈）：`cublas64_12.dll is not found` 导致 pipeline 静默 fail。
  根因：PyInstaller 打包环境没有 nvidia-cublas-cu12 的 DLL；`ctranslate2.get_cuda_device_count()` 误报可用。
  修复：`whisper_worker` 增加 `cuda_runtime_ready()` 真实可用性探测 + 运行时 GPU→CPU 自动回退；
  `pipeline` 统一从 settings 读取 `whisper_device`；`selftest` 也改用统一设备选择。
  设置页加「识别设备」下拉 + 真实 GPU 状态显示。
- **安装包**：仍沿用 2026-09-03 的 `installer/ClassroomAssistant-Setup-x64.exe`；源码已修复，
  **待重新运行 `build_exe.bat` / `build_release.ps1` 后再发版**。
- **桌面入口已验证**：安装后桌面出现"课堂助手.lnk"，目标为已安装的 `ClassroomAssistant.exe`。
- **数据与安装分离**：用户数据默认在 `%LOCALAPPDATA%\ClassroomAssistant`，卸载不会删除数据。

## 五、已知限制（设计取舍）

1. 同一时间只处理一个活动任务，避免长录音互相抢占。
2. “已完成”由用户在重要事项页手动勾选，系统不自动判断。
3. 超长录音目前整段入库，流式处理是后续优化项。
4. 默认使用 4-bit 量化模型；更高质量模型需要手动增加清单配置。
5. DPAPI 密钥绑定当前 Windows 用户和设备，换机后需重新填写。
6. 删除课程为归档，不直接硬删历史。
7. 被证据关卡判定为 `rejected` 的事项默认不展示，也不进入搜索索引，但会保留在数据库中供诊断。
