# 模型与电脑配置

本文对应课堂助手 2.0 桌面版源码候选。模型名称和用途已固定为本地 Qwen 链路；本文不会把“源码支持下载模型”误写成“公开安装包已经内置模型”。

## 软件使用的模型

| 用途 | 模型 | 精度/格式 | 权重大小约数 | 作用 |
| --- | --- | --- | ---: | --- |
| 录音转文字 | [Qwen3-ASR-0.6B](https://huggingface.co/Qwen/Qwen3-ASR-0.6B) | Transformers / Safetensors | 1.88 GB | 把课堂录音识别为带时间信息的原文 |
| 整理课堂文字 | [Qwen3-4B-GGUF](https://huggingface.co/Qwen/Qwen3-4B-GGUF) 的 `Qwen3-4B-Q5_K_M.gguf` | GGUF，Q5_K_M 量化 | 2.89 GB | 将识别文字整理成中文课堂笔记、概览和事项 |

两个模型权重合计约 **4.77 GB（4.44 GiB）**。两者均标注 Apache-2.0；随可下载成品分发时仍须保留上游许可和必要的第三方声明。模型权重不包括推理运行库、应用程序或安装临时空间。

## 运行时也必须随成品处理

权重文件不是完整的软件运行环境。桌面程序还需要：

- Qwen ASR 的独立 Python/PyTorch 运行环境。为避免与桌面 WebView 的原生库冲突，它应作为独立本地进程运行。
- `llama.cpp` 的 `llama-server` 和对应 Windows 运行库，用于加载 GGUF 文字模型。
- Windows x64 与 Microsoft Edge WebView2 Runtime。

2.0 源码候选目前会把模型放在 `%LOCALAPPDATA%\ClassroomAssistant\models`，并提供首次下载流程；Qwen 工作进程会查找外部 Python 环境。**2.0 尚未生成新的公开安装包**；当前打包配置也不会把模型权重和 Qwen/PyTorch 运行环境放进桌面程序。因此，源码中有模型下载功能不等于干净电脑安装后即可直接处理录音。正式发布前应把运行环境和模型一并打包/安装，并在干净 Windows 环境验收。

## 电脑配置建议

上游没有为本应用提供经过验证的整机最低配置；下面是按本项目模型大小给出的保守建议，不是性能保证。

- **系统**：Windows 10/11，64 位；需要 WebView2 Runtime。
- **内存**：建议至少 16 GB；同时使用其他大型软件或处理较长课程时，建议 32 GB。
- **显卡**：NVIDIA 显卡可加速识别和文字整理；建议 8 GB 或以上显存。没有合适显卡时可尝试 CPU，但速度会明显较慢，且长录音耗时尚未给出统一保证。
- **磁盘**：模型权重本身约 4.77 GB。安装程序、运行库、下载/解压临时文件及用户录音还会额外占用空间；在最终安装包实测前，建议预留至少 15 GB 可用空间。
- **网络**：若下载模型或运行环境，首次安装/准备阶段需要稳定网络；完整准备并通过自检后，日常录音识别和课堂整理应在本机运行。

发布说明必须分别写出“安装包体积”“安装后占用”“模型权重体积”，不要把它们混成一个大小。CPU 推理速度、最低显存和最低磁盘空间仍需在干净 Windows 设备上实测后才能收紧为正式最低要求。

## 完整下载包的发布限制

GitHub Release 的单个附件必须小于 2 GiB，而课堂整理 GGUF 单个权重约 2.89 GB。因此，若公开下载仍使用 GitHub Release，完整离线包不能作为单个附件直接上传：需要将大文件安全分卷，并让安装入口自动下载、校验和放置所有组件，或提供多个必须一起下载的离线分卷。无论采用哪种方式，安装完成后的程序都必须能在没有系统 Python、没有 Hugging Face 登录、没有额外手工下载模型的干净电脑上通过启动和模型自检。
