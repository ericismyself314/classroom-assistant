# 安装说明（普通用户）

> 本文面向**不使用命令行**的普通用户。推荐使用 `ClassroomAssistant-Setup-x64.exe` 安装，不需要 Python、Node 或命令行。

---

## 1. 使用打包好的版本（推荐）

1. 双击 `ClassroomAssistant-Setup-x64.exe`，按提示完成安装；“创建桌面快捷方式”默认已勾选。
2. 双击桌面的“课堂助手”。
   - 首次打开会显示三步向导。点击“一键准备离线模型（推荐）”，保持联网并耐心等待（约 2–5 GB）；之后可以离线使用。
   - 若系统提示「需要 WebView2 运行时」：Windows 11 通常已自带；Windows 10 请到微软官网安装「Microsoft Edge WebView2 Runtime」（免费的系统组件）。
3. 如果课表已经导入，直接在“本周”点一节课、上传录音，完成后查看重点和原文；没有导入课表时，再按页面提示新建学期和课程。

**数据存放在哪里？**
默认在 `C:\Users\<你的用户名>\AppData\Local\ClassroomAssistant\`。如需换盘（C 盘空间紧张），在「设置」页修改数据目录即可（修改后需重启应用）。

---

## 2. 从源码运行（需要 Python 与 Node）

### 2.1 准备环境

- 安装 **Python 3.13**（勾选「Add to PATH」）。
- 安装 **Node.js 20+**（含 npm）。
- 安装 **Microsoft Edge WebView2 Runtime**（Windows 10 需要；Win11 自带）。

### 2.2 安装与启动

在「课堂助手」项目文件夹内，按住 Shift 右键 →「在此处打开终端」，依次执行：

```bash
# 创建虚拟环境
python -m venv venv
venv\Scripts\activate

# 安装后端依赖
pip install -r requirements.txt

# 构建前端
cd frontend
npm install
npm run build
cd ..

# 启动应用（会弹出窗口）
python run.py
```

> 只想跑后端做调试：`python run.py --no-gui`，终端会打印本地地址。

### 2.3 一键打包成 exe（给同事/自己分发）

双击运行项目里的 `build_exe.bat`，脚本会自动建虚拟环境、装依赖、构建前端并生成
`dist\ClassroomAssistant\ClassroomAssistant.exe`。生成后即可像第 1 节一样双击使用。

---

## 3. 第一次使用的建议流程

1. 首次向导点击**一键准备离线模型（推荐）**，等待两项模型准备完成。
2. 如果没有预置课表，填写本学期和第一门课程；时区一般保持“北京/上海”即可。已有课表可跳过这一步。
3. 以后每次只需在“本周”点开课程 → **上传录音**（也可导入转写文字）。
4. 等待处理完成，查看“课堂概览 / 重要事项 / 转写原文”。
5. 在“重要事项”里勾选已完成；在“搜索”里跨课堂查关键词。

---

## 4. 常见问题

- **卡在「下载模型中」**：首次下载量大，请保持联网。若公司网络限制 HuggingFace/GitHub，请更换网络或手动把模型放到数据目录（见《数据存储与隐私》）。
- **识别很慢**：设置页可切换为「仅 CPU」以避免显卡驱动反复重试；默认「自动」会优先使用可用的 NVIDIA GPU。首次加载 Qwen3-ASR-0.6B 需要几十秒，之后会复用模型服务。
- **弹黑窗报错 / 无法启动 GUI**：多为缺 WebView2 运行时，装好后重启即可；也可先用 `python run.py --no-gui` 验证后端是否正常。
- **数据备份**：设置页「备份」会下载一个 ZIP；重装系统前务必先备份。
