# 安装说明（普通用户）

> 本文面向普通用户。3.0 提供 Windows 便携压缩包；桌面程序无需 Python 或 Node 即可打开。语音识别另需本地 Python 3.12 + Qwen 运行依赖。

---

## 1. 使用打包好的版本（推荐）

1. 在 [GitHub Releases](https://github.com/ericismyself314/classroom-assistant/releases/latest) 下载 `ClassroomAssistant-3.0.0-win-x64-portable.zip`。
2. 将整个压缩包解压到一个固定文件夹，双击其中的 `ClassroomAssistant.exe`。请保留同目录的 `_internal` 文件夹，不要只移动 exe。
3. 首次打开后按向导准备本地模型，保持联网并预留约 2–5 GB 空间；准备完成后，录音识别和课堂整理默认在本机运行。
4. Windows 11 通常已带 WebView2；Windows 10 若提示缺少运行时，请安装 Microsoft Edge WebView2 Runtime。
5. 首次语音识别前需有 64 位 Python 3.12 和 Qwen 语音运行依赖。若尚未安装，请打开终端运行 `py -3.12 -m pip install "qwen-asr==0.0.6"`；已配置好 Qwen 的 Python 3.12 可直接使用。
6. 在“本周”新建自己的学期和课程，再上传多个录音、用麦克风录音，或导入已有文字稿。

**数据存放在哪里？**
默认在 `C:\Users\<你的用户名>\AppData\Local\ClassroomAssistant\`。如需换盘（C 盘空间紧张），在「设置」页修改数据目录即可（修改后需重启应用）。

---

## 2. 从源码运行（需要 Python 与 Node）

### 2.1 准备环境

- 安装 **64 位 Python 3.12**（勾选「Add to PATH」）。
- 安装 **Node.js 20+**（含 npm）。
- 安装 **Microsoft Edge WebView2 Runtime**（Windows 10 需要；Win11 自带）。

### 2.2 安装与启动

在「课堂助手」项目文件夹内，按住 Shift 右键 →「在此处打开终端」，依次执行：

```bash
# 创建虚拟环境
python -m venv venv
venv\Scripts\activate

# 安装后端依赖
pip install -r requirements.txt

# 构建前端
cd frontend
npm install
npm run build
cd ..

# 启动应用（会弹出窗口）
python src/main.py
```

> 只想跑后端做调试：`python src/main.py --no-gui`，终端会打印本地地址。

### 2.3 一键打包成 exe（给同事/自己分发）

双击运行项目里的 `build_exe.bat`，脚本会自动建虚拟环境、装依赖、构建前端并在系统临时目录生成
`ClassroomAssistant\ClassroomAssistant.exe`。发布时请连同 `_internal` 目录一起压缩分发；模型权重由使用者首次打开应用后下载。

## 3. 第一次使用的建议流程

1. 首次向导点击**一键准备离线模型（推荐）**，等待两项模型准备完成。
2. 如果没有预置课表，填写本学期和第一门课程；时区一般保持“北京/上海”即可。已有课表可跳过这一步。
3. 以后每次只需在“本周”点开课程 → **上传录音**（也可导入转写文字）。
4. 等待处理完成，查看“课堂概览 / 重要事项 / 转写原文”。
5. 在“重要事项”里勾选已完成；在“搜索”里跨课堂查关键词。

## 4. 常见问题

- **卡在「下载模型中」**：首次下载量大，请保持联网。若公司网络限制 HuggingFace/GitHub，请更换网络或手动把模型放到数据目录（见《数据存储与隐私》）。
- **Windows 显示未知发布者提示**：当前便携程序未使用代码签名证书；请确认下载来源为本项目的 GitHub Releases。
- **识别很慢**：设置页可切换为「仅 CPU」以避免显卡驱动反复重试；默认「自动」会优先使用可用的 NVIDIA GPU。首次加载 Qwen3-ASR-0.6B 需要几十秒，之后会复用模型服务。
- **语音识别无法启动**：确认已安装 64 位 Python 3.12 和 `qwen-asr==0.0.6`；也可在终端运行 `py -3.12 -m pip install "qwen-asr==0.0.6"` 后重启应用。
- **无法启动 GUI**：多为缺 WebView2 运行时，装好后重启即可；也可先用 `python src/main.py --no-gui` 验证后端是否正常。
- **数据备份**：设置页「备份」会下载一个 ZIP；重装系统前务必先备份。
