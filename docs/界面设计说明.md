# 界面设计说明

> 说明：本页以下内容记录早期的白色磨砂方案。当前未发布的源码已调整为浅灰背景、白色与深色卡片、森林绿点缀；主页选课后可选择电脑录音或上传，详情页增加录音文件列表与底部播放条。已有下载包尚未更新。

本次源码更新采用作者确认的课程总览、录音与转写、课堂整理三张概念图作为方向。示例课表、课程名称和笔记仅用于隔离验证，应用实际显示本机已有数据。

## 视觉与布局

- 背景始终纯白，强调色沿用 `#2E7D4F`，选中区域使用 `#E8F3EC`。
- 玻璃质感限定在卡片内：乳白半透明表面、柔和边缘高光、轻微内阴影和局部背景模糊；没有整页渐变或装饰性背景。
- 连续圆角使用浏览器支持的 squircle 渐进增强；不支持时回退到普通圆角。文字不会被模糊。
- 卡片水平间距 16px，主行纵向间距 24px，堆叠卡片间距 16px。采用系统字体和统一线条图标，保留键盘焦点与减少动态效果设置。
- 窄窗口下卡片纵向排列，周课表保留可横向滚动的七天视图，不把整页撑宽。

## 课程总览

本周课表是主区域，右侧为下一节课和待办，下方为最近课堂。课程按真实开始时间生成行，显示结束时间；同一时段有多门课程时并列堆叠，晚课和不规则时间不会被固定网格遗漏。课程可跳转到已有课堂或带课程信息的录音页。

下一节课优先覆盖正在进行的课程，今日结束后继续查找所显示周内后续日期。查看历史周时不虚构“下一节课”。首页待办包括已确认但未完成的事项，并标注仍待核对的信息；完成失败时保留事项。

新增只读 `/api/dashboard` 接口，以有上限的查询读取当前学期的三条最近课堂和三条待完成事项；排除归档课程、其他学期和已拒绝的候选，不探测或启动模型。

## 录音与转写

计时、暂停、继续、结束、试听、保存和多段上传均沿用实际录音流程。波形来自 Web Audio 麦克风输入，未录音或暂停时显示静止基线，不显示预设波形。右侧转写预览来自选定课堂的已保存内容；没有内容时显示明确的等待状态。本次未加入实时流式识别。

## 课堂整理

左侧为课堂概览、转写原文、重要事项和待核对四个视图，右侧为可回听定位的内容时间轴和事项。保留手动修正、原文出处、重新处理和历史版本入口。播放器支持逐段选择、播放/暂停、进度跳转、音量与倍速；导出为本地文本文件。
